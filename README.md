# lineage-bench-results

This repository contains results of [lineage-bench](https://github.com/fairydreaming/lineage-bench) benchmark.

## lineage-8_16_32_64

The [lineage-8_16_32_64](https://github.com/fairydreaming/lineage-bench-results/tree/main/lineage-8_16_32_64) directory contains results for models tested from 2025-01 to 2025-03.
During this period lineage-8, lineage-16, lineage-32 and lineage-64 problem sizes were used.
After this period difficulty was increased due to increase in observed performance of tested models.

## lineage-8_64_128_192

The [lineage-8_64_128_192](https://github.com/fairydreaming/lineage-bench-results/tree/main/lineage-8_64_128_192) directory contains results for models tested after 2025-03.
During this period lineage-8, lineage-64, lineage-128 and lineage-192 problem sizes were used.
Since the observed model performance increased greatly again during this period, the current difficulty level seems to already be too low for top-performing models.
